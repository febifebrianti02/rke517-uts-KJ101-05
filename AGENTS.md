# Instructions for AI agents in this repository

This is an individual exam repository. The student is accountable for every line.
- Use only the facts in the case files (brief, interview, voice note, form photo, staff chat).
  If something is not there, write it as an open question or label it "(my assumption)".
- If two sources disagree, do not choose silently. Point it out to the student.
- Fictional data only. No real names, NIK or medical record numbers.
- Never commit to main. One issue = one branch = one pull request.
- Show the student your plan and wait for their OK before changing files.
